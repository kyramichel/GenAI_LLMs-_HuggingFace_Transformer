

## Fine-Tuning & Deploying Hugging Face Models

This repository contains practical work on fine-tuning and deploying transformer-based models using the Hugging Face ecosystem.

It focuses on applied workflows for adapting pre-trained models to specific tasks and deploying them for inference.

---

## Scope

* Fine-tuning transformer models using Hugging Face Transformers
* Dataset preparation and training workflows
* Model evaluation and performance tuning
* Deployment of models to Hugging Face Hub
* Basic inference pipelines and usage patterns

---

## Focus Areas

* Transfer learning for NLP and GenAI tasks
* Practical fine-tuning techniques (training loops, hyperparameters, optimization)
* Model packaging and deployment on Hugging Face Hub
* End-to-end pipeline: from training to inference
